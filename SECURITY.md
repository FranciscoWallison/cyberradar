# Política de segurança

Encontrou uma vulnerabilidade neste projeto (site, pipeline ou workflows)? **Não abra issue pública.**
Use *Security → Report a vulnerability* (GitHub Private Vulnerability Reporting) neste repositório.

Erros de conteúdo (CVE com dado errado, resumo de IA incorreto) podem ser reportados normalmente por issue
ou pelo formulário indicado no site.
